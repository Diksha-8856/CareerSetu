# CareerSetu

CareerSetu is a modern **job portal and recruitment management system** built to streamline the hiring process for recruiters and provide a smooth application experience for job seekers. It combines a clean, responsive UI with powerful backend integration to deliver a professional dashboard for managing jobs, applicants, and analytics.

---

## 🚀 Features

### For Recruiters
- **Dashboard Overview**: Summary widgets for active jobs, applicants, interviews, and hires.  
- **Job Postings Management**: Create, edit, and view job postings with status badges (Active, Closed, Draft).  
- **Applicant Tracking**: Profile cards showing applicant photo, experience, applied role, applied date, email, phone, and status (Pending, Followed, Shortlisted, etc.).  
- **Interview Scheduling**: Upcoming interviews section with candidate details, date, and time.  
- **Analytics**: Hiring trends and department-wise statistics visualized with charts.  
- **Enquiry Handling**: Add and manage recruiter enquiries with structured forms.

### For Applicants
- **Profile Cards**: Applicant details displayed in professional card format (photo, name, experience, applied role, applied date, contact info, status).  
- **Responsive UI**: Clean Bootstrap-based design with pill-shaped buttons, hover effects, and consistent branding.  
- **Career Site Integration**: Applicants can apply directly and track their progress.

---

## 🛠️ Tech Stack
- **Frontend**: React, Bootstrap, CSS (custom hover + pill styles)  
- **Backend**: Node.js, Express, Multer (for file uploads), REST APIs  
- **Database**: SQL schema design for jobs, applicants, recruiters, and enquiries  
- **Charts**: Chart.js / Recharts for analytics visualization  

---

## 📂 Project Structure
- `Dashboard/` → Recruiter dashboard with summary widgets, job postings, applicants, interviews, analytics  
- `Applicants/` → Applicant cards with profile details and status badges  
- `Jobs/` → Job posting creation and management forms  
- `Enquiry/` → Enquiry form for recruiter queries  
- `Profile/` → Recruiter profile page with editable details  

---
